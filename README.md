# PyTerra

一款用 Python + pygame 编写的类 Terraria 2D 沙盒游戏。纯程序化生成，零美术资源——所有贴图都在运行时由代码绘制。

> 运行 `python tests/smoke_test.py` 会在 `docs/` 下生成真实运行截图（白天 / 夜晚火把光照 / 背包合成界面）。

## 玩法特性

- **程序化世界生成**：起伏地形、土层/岩层、随机洞穴网络，以及按深度分布的煤、铜、铁、金四种矿脉；地表自动生成树木。
- **挖掘与放置**：左键挖掘方块（带进度条），右键放置方块；不同矿石需要对应等级的镐子。
- **光照与昼夜循环**：阳光沿地表照射并渗入洞穴，火把提供稳定光源；完整的白天/黄昏/黑夜/黎明循环，夜晚天空出现星星与月亮。
- **工具与合成**：木镐 → 石镐 → 铁镐 → 金镐的升级路线，木剑/铁剑武器；合成台（Work Bench）解锁高级配方，贴近 Terraria 的合成逻辑。
- **敌人与战斗**：白天地表生成史莱姆，夜晚生成僵尸（会跳跃翻越障碍）；生命 hearts、受伤击退、无敌帧、生命回复与死亡重生。
- **背包系统**：10 格快捷栏 + 30 格背包，堆叠、拖拽交换、悬停提示。
- **存档**：F5 随时保存，退出自动保存，下次启动自动读档。

## 运行

```bash
pip install -r requirements.txt
python main.py          # 继续上次存档（如存在）
python main.py --new    # 强制生成新世界
```

## 操作

| 按键 | 功能 |
| --- | --- |
| A / D | 左右移动 |
| 空格 | 跳跃 |
| 鼠标左键 | 挖掘方块 / 攻击敌人 |
| 鼠标右键 | 放置选中方块 |
| 1-0 / 滚轮 | 切换快捷栏 |
| E | 背包与合成界面 |
| F5 | 保存游戏 |
| H | 帮助面板 |
| ESC | 退出 |

## 游戏提示

- 开局自带木镐、木剑和 10 个火把。
- 史莱姆掉落凝胶（Gel），凝胶 + 木头 = 火把。
- 挖 8 块木头合成工作台，站在工作台附近才能制作石镐等高级工具。
- 铁矿石需要石镐，金矿需要铁镐——往深处挖，但小心夜晚的僵尸。

## 项目结构

```
main.py        游戏主循环、相机、挖掘/战斗/放置、昼夜渲染
world.py       世界生成（地形/洞穴/矿脉/树）与双通道光照系统
entities.py    玩家、史莱姆、僵尸、掉落物（AABB 物理）
tiles.py       方块注册表（硬度、镐力需求、掉落、发光）
items.py       物品注册表（材料、放置物、工具、武器）
inventory.py   背包与快捷栏
crafting.py    合成配方与工作台判定
ui.py          程序化贴图、HUD、背包/合成界面
noise.py       确定性值噪声（地形生成）
```
